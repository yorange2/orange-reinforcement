规则与说明

牌堆：54 张去掉大小王和四个 2，剩 48 张，每人 16 张。点数 3 < 4 < … < K < A，没有 2 和王。

先手：谁摸到 ♦3 谁先出，且第一手必须包含 ♦3。

牌型：单张、对子、三张、三带一、三带二、顺子（≥5 张）、连对（≥2 对）、 飞机（≥2 组连续三张，可带单或带对）、炸弹（四张同点，压任何非炸弹）。

跟牌：同牌型、同长度、点数更大才能压；跟不起或不想跟就"不要"； 其余两家都不要之后，最后出牌的人重新自由出牌。先出完手牌者胜。

怎么玩：点手牌选中，再点出牌。选错了点取消选择。

那些打分是什么：模型给每个候选打一个分，再在当前合法的候选里做 softmax 得到概率，取最高的出。分数本身没有单位，只有相对大小有意义。
