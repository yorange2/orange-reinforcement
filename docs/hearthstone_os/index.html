炉石传说（orange-stone 引擎）← 回首页

同一款简化炉石跑在 Rust 模拟器 orange-stone 上： 经典卡池、官方规则开局（先手第一回合 1 水晶、后手 4 张 + 幸运币）、 CoW 克隆廉价恢复整回合 beam 搜索。

战绩表

每格 600 局，先后手轮换，随机基准 50%。模型 68k 参数，PPO + GAE(λ=0.5)，3 万局。

引擎与实现

  • 引擎：orange-stone（MIT）， ECS + CoW GameState + 事件驱动规则引擎，316 张经典卡
  • 特征：v7 = 199 维（31 动作 + 168 局面），结构化视图上构建
  • 搜索：整回合 beam（宽度 8），用 Env.clone() 恢复——rosetta 方案被 拷贝构造删除堵死的收益，在 orange-stone 上一行绑定
  • 性能：引擎批量 ~4,200 局/s（≈9× RosettaStone 绑定）；并行训练 ~170 局/s

怎么玩（终端人机）

.venv/bin/python -m hearthstone_os.play --human --bot rule
# 打印局面和动作列表，输入下标出牌；q 结束回合

训练与复现

.venv/bin/python -m hearthstone_os.train --episodes 30000 --save hearthstone_os/models/agent.pt
.venv/bin/python -m hearthstone_os.bench --model hearthstone_os/models/agent.pt
